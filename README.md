# How To Install?

1. Wear OS Watch에서 개발자 모드를 켭니다
2. 무선 디버깅을 켭니다
3. PC에서 ADB를 이용해 워치에 연결합니다
4. 아래 명령어를 입력해 WatchFace를 설치합니다

```powershell
adb install <file_name.apk>
```
